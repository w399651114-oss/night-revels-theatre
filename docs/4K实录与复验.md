# 4K 操作演示的录制与复验

演示逐次点击网页控件，收录标签页里的完整界面、Three.js 画面和该标签页送出的立体声。画面中的黄圈表示一次真实的浏览器按下事件；白色指针跟随事件坐标。顶端字幕标出段落、条件和实验解释。试听过程中的自报用于展示记录功能，属于模拟操作。

## 本地重建

使用支持标签页捕获和 AVC/AAC 编码的桌面 Chrome。示例命令从仓库根目录运行，最后一个参数指定本地交付目录。录制脚本使用独立临时浏览器配置，网页音轨排除自动增益、回声抵消与降噪。脚本默认启动仅回环地址可达的 Vite 预览并在退出时关闭。

```sh
npm ci
npm run build
python3.12 -m venv /tmp/夜宴录制环境
/tmp/夜宴录制环境/bin/python -m pip install -r scripts/demo/requirements.txt
node scripts/demo/capture.mjs --sample ../夜宴折屏交付/小样
/tmp/夜宴录制环境/bin/python scripts/demo/finish.py --sample ../夜宴折屏交付/小样
node scripts/demo/capture.mjs ../夜宴折屏交付
/tmp/夜宴录制环境/bin/python scripts/demo/finish.py ../夜宴折屏交付
/tmp/夜宴录制环境/bin/python scripts/demo/notes.py ../夜宴折屏交付 docs/4K分镜与验收.md
```

需要录制指定的修订版时，可将 `RECORD_URL` 指向已经构建并预览的网页。通过 Playwright 的 Chrome 稳定通道启动。浏览器操作、录制脚本、校准与剪辑只在操作者的设备运行。公开站点的导出由用户浏览器下载。

## 画面与声音

- 录制视口为 1920 × 1080 CSS 像素，设备像素比为 2，在界面中先选择精细画质。Chrome 直接捕获当前标签页的 3840 × 2160 像素。WebGL 部分的尺寸随页头、工具条和画卷动线所占空间变化，文字与折屏一并录入。
- `getDisplayMedia` 请求同一标签页的绘图与音轨。原始文件保留浏览器输出的可变帧率视频，音频采样率按实际捕获设备记录。浏览器默认静音会让标签页采集得到全静音，启动参数显式移除该选项。验收脚本还从解码数据检查整条音轨与 A/B 窗口。
- 两次片头校准与一次片尾校准都在保留片段外。每次在同一动画帧点亮白块、从 Web Audio 送出 2 kHz 短音。逐帧读取白块的首帧，按 5 毫秒窗检测短音起点，取三个偏差的中位数对齐全片。
- ffmpeg 以实际媒体时间采样为 24 fps，H.264 / YUV 4:2:0 / BT.709，AAC 48 kHz 双声道。仅对整部作品设置一个固定增益。源端空间衰减、甲乙之间的鼓声差异和留白中的静默保留在同一音量标尺上。
- 镜头脚本保留桌面四次固定路线的完整行进。窄屏段将同一网页放入 390 × 844 CSS 像素的独立视口，以便在固定 4K 画幅内看到手机尺寸下的抽屉和行进键。这里使用桌面指针操作。

## 本地文件

| 文件 | 用途 |
| --- | --- |
| `韩熙载夜宴图-折屏剧场与听觉实验-4K.mp4` | 可直接播放的成片 |
| `浏览器原始实录.mp4` | 浏览器直接输出，首尾含同步校准信号 |
| `实录事件.json` | 浏览器属性、实际绘图尺寸、采集轨道、镜头和点击的时间戳 |
| `演示点击-四回合逐次实验记录.json` | 由网页下载的四个桌面试次轨迹与自报 |
| `4K成片验收.json` | 完整解码结果、文件摘要、同步偏差、同音量 A/B 窗口与时码 |
| `4K逐帧SSIM.txt.gz` | 每一帧相对原始捕获图像的结构相似性结果 |
| `小样/` | 校准小样、对应剪辑和独立验收记录 |

使用系统播放器打开成片，戴耳机从切片一甲版听起，到乙版保持设备音量一致。验收 JSON 的时间从成片第一帧算起。切片一同时有琵琶，比较 60 至 180 Hz 的鼓声频带；切片二取留白内同一段路线，比较两次的全频均方根。AAC 静默区的微小数值按解码结果报告。演示点击的时刻和先后仅证明这些操作已录下，研究结论须由正式的实验数据支持。

本次真实录制的逐段时间、控件操作、同程采样响度与文件校验值见[分镜与验收记录](./4K分镜与验收.md)。
