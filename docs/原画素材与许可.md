# 原画素材与许可

作品为故宫博物院藏《韩熙载夜宴图》卷。馆方著录传顾闳中作，现存卷为南宋摹本。五段名称采用馆方条目的“听乐、观舞、暂歇、清吹、散宴”。简化标签中的宾客、侍者等泛称仅描述画中可见活动。[故宫博物院藏品条目](https://www.dpm.org.cn/collection/paint/228200.html)

站内长卷缩略图展示五段绘画本幅。装裱、引首与卷后题跋见源文件。五段证据图保留原画中的交叠笔画。三维贴片按手工画出的可见轮廓和窄带色差掩模裁切。和尚衣褶和暂歇漆榻的局部遮挡用相邻同画纹理补色，屏前宾客的两处袍脚借自同卷执拍者，在清单中标记为 `occludedPaint`。人物背面、身体厚度、家具背面的史实资料无法从这件二维作品读出。贴片层间距离和虚拟米尺均为实验设计参数。清吹相邻的合奏人物仍然保留为一组，前一段家具上叠压的人物也有成组保留。靠近画片可见少量绢色边缘；从侧面观察会看见画片的平面结构。

## 坐标与资产清单

`public/art/art.json` 按卷首至卷末列出五段。文件路径相对于发布页根目录。每段 `sourceRange` 表示 4,720 × 396 坐标系内的横向区间。每个贴片的 `sourceBox` 为本段图中从左上原点计的 `[左,上,右,下]`。`x` 是相对本段中心的横向米数，`z` 朝观者为正，`height` 是推定高度，`aspect` 是纹理宽高比，锚点在图像底边中心。场景可据几何遮挡和观察路径对初始摆位再作调整。

## 重建贴片与证据图

运行网页或构建 Vite 项目只需 Node.js 依赖。以下步骤用于修改画片。仓库随附 14,160 × 1,188 的配准绘画母版 `scripts/art/master.webp`，构建工具从本地文件读取。

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r scripts/art/requirements.txt
PYTHONDONTWRITEBYTECODE=1 python scripts/art/build.py
```

通过 `scripts/art/outlines.py` 调整人物边界、局部补色和建议摆位。生成时依据原画笔线细化轮廓，再以透明 WebP 保存。GitHub Pages 中仅部署 `public/art` 的运行文件。源码母版不会发往浏览者。

## 从馆藏扫描图重新生成母版

1. 从上表的 Commons TIFF 页下载原文件到仓库外的临时目录。文件 588,225,204 字节，SHA-256 为 `f283b4325a22c5e3c2a9ecac6d7ce74c51dc75cccd9793f62ac3d8a45ded845a`。
2. 在 macOS 将完整装裱图等比缩到 34,600 像素宽。初次制作使用系统自带的 `sips`。其他系统也可生成同样尺寸、方向和色彩空间的 RGB JPEG；编码器会引入细小像素差异。
3. 运行下面的命令。随附配准表由两张公版图的 SIFT 特征、最近邻比值筛选和分区 RANSAC 生成，每隔 80 个横坐标取一次局部相似变换；脚本插值取得连续对应。初版配准母版的 SHA-256 为 `bf892ff803012647d7aaf1c816575025f5f305eacc28059c4bffe52bd35aa357`。

```sh
sips -Z 34600 -s format jpeg "/临时目录/韩熙载夜宴图.tif" --out "/临时目录/整卷.jpg"
python scripts/art/register_master.py "/临时目录/整卷.jpg"
PYTHONDONTWRITEBYTECODE=1 python scripts/art/build.py
```

源 TIFF 及配准检查用 JPEG 留在制作端的临时目录。提交的母版足以重新生成网站中的图像。
