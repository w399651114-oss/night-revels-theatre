# 两个切片怎样复核

2026 年 11 月 20 日使用 Apple M1 Pro / 16 GB、Chrome 157.0.8103.79 测试。首次复核使用的旧版本为 `acacd85`。当时在固定桌面镜头约 3.68 米处已有舞者像素，乙版仍在 4.20 米处开鼓；390 × 844 视口中实验面板占画布约 89.1%。这两项分别改为依深度遮挡揭帧、开始试听后在画布上方显示紧凑控件。

## 实际音轨和画面的先后

固定试听从 2.25 米开始，每秒走 0.66 米。每帧在声部增益之后、空间衰减之前读取 512 点 PCM 的均方根，以 0.0001 为起音检出阈值。下表以按下“从同一起点试听”后程序开始记录的时刻为零。鼓轨开放由程序报告，首次检出来自独立分析器。逐帧采样的精度受显示刷新率限制，耳机和听者的延时另计。结果为一次测试的观测值，镜头尺寸和设备可改变读数。

| 视口 | 条件 | 舞者首次揭帧 | 鼓轨开放 | 鼓声首次检出 |
| --- | --- | --- | --- | --- |
| 1440 × 900 | 甲 | 3.688 米 / 2213 毫秒 | 14 毫秒 | 46 毫秒 |
| 1440 × 900 | 乙 | 3.688 米 / 2213 毫秒 | 2213 毫秒 | 2229 毫秒 |
| 390 × 844 | 甲 | 3.712 米 / 2255 毫秒 | 6 毫秒 | 38 毫秒 |
| 390 × 844 | 乙 | 3.709 米 / 2246 毫秒 | 2246 毫秒 | 2262 毫秒 |

两次乙版在揭帧前 60 毫秒以前的样点中，鼓声部最高 RMS 均为零。切片二取进入留白后 250 毫秒起、离开前 100 毫秒止的管轨样本，甲的线性 RMS 为 0.0824，乙为零。成片另从解码后的立体声混音测量。[同位置的成片复听时码](4K分镜与验收.md)

## 记录与复听

1. 打开“声场实验”，选择切片和甲或乙，再点“从同一起点试听”。操作条出现，全屏宽度都可用来观察画面。两种测试视口中，操作条与画布的矩形交集均为零。
2. 可以让网页自动走到终点，也可驻足、切换版本、手动回退或继续。听见、看见或感觉声音停止时可以按相应按钮。按钮记录的是点击时刻，带有人的反应时间。
3. 从实验面板下载逐次实验记录 JSON。每回合含条件顺序、起止位置、设备视口、音频采样率、画质、方向、视点、轨迹、状态和毫秒时间戳。同页刷新可恢复；关闭标签页前应下载。没有服务器收集参与者数据。
4. 自主回合验收实际点击驻足与自报，切换甲乙、按键回退、结束、刷新、下载，并核对事件次序与轨迹。演示中四个回合的按钮点击由脚本执行。本次没有招募参与者或测量人的知觉阈值。

## 复跑

在完成 `npm ci` 与 `npm run build` 后运行以下命令。测试会启动本机静态预览，结束后关闭。若机器安装的是 Playwright Chromium，可省略 `BROWSER_CHANNEL=chrome` 并先运行 `npx playwright install chromium`。设置 `CHECK_URL` 可以对已部署版本复跑。

```sh
BROWSER_CHANNEL=chrome npm run test:browser -- --media
BROWSER_CHANNEL=chrome REPORT_PATH=声画实测.json npm run test:study
BROWSER_CHANNEL=chrome REPORT_PATH=完整巡游.json npm run test:tour
```

巡游从起始视点 1.5 米连续行至卷末 27 米，经过全部五幕与留白。标准画质，声音开启，1440 × 900 视口，1440 × 641 绘图缓冲，ANGLE Metal。47.06 秒内采得 2821 个浏览器动画帧间隔，平均 59.94 fps，中位 16.7 毫秒，P95 为 16.8 毫秒，最长 33.4 毫秒。4K 录制的原始帧间隔另见镜头表。此次移动端验收在同一台 Mac 上模拟触屏尺寸。
