# 原卷对照与人物动作

## 从剧场返回原卷

「原卷对照」显示故宫博物院藏宋摹本的绘画本幅。五个按钮按卷首在右、卷末在左排列。点段名跳转，选人物或器物可见来源框。鼠标可以按住横拖，手机可以左右滑动；全卷定位尺、卷首卷末按钮或左右方向键也能移图。在窄屏上图像保持可辨读的高度，超出屏幕的部分供横移观看。

来源框读取 `public/art/art.json`。本幅横坐标为 0–4553，图像标尺高 396。以每段 `sourceRange[0]` 加上本段裁切范围 `sourceBox` 中的横坐标，纵坐标直接沿用裁切标尺。画片若含遮挡补绘，回卷后显示原画中的实际笔墨。框的范围包含人物与周边绢地；框线是操作标注。

留白按钮指向本幅横坐标 710–760、纵坐标 8–388 的素绢。该处位于坐客与临屏女侍之间，可以在图上一边滑动一边对照相邻人物的间距。这是研究者选择的观察区域。剧场对应的 20.95–23.55 米共有 2.60 米，供两种声音延续方式在相同路线比较。两套刻度服务于图像取样与实验行走，无法据此换算原建筑长度。

## 四处局部动作

| 场次 | 从画上提取的部位 | 虚拟运动 |
| --- | --- | --- |
| 听乐 | 琵琶乐伎的前臂、手腕和拨子 | 以袖肘为支点，每 0.5 秒一次下拨与回拨。 |
| 观舞 | 韩熙载抬起的前臂、抓握的手和圆头鼓槌 | 使用鼓轨独立相位，拍头落槌、回弹、再蓄力；每八个脉冲的第六个休止。 |
| 观舞 | 舞者折返腰带前的一段衣袖 | 围绕肘部小幅收放，沿同一鼓组的相位。 |
| 清吹 | 女乐按管的手势和一段竖管 | 以近唇处为支点，跟随 1.5 秒的合成管声乐句小幅摆动。 |

单幅绘画提供静态姿态。关节活动范围、方向、周期与合成声音均为实验推定。抠取活动部位后，其静态底图用邻近色补足，动件保留原位置、朝向与源图标尺。每个动作是父画片的子网格，围绕局部关节旋转。躯干和衣裙维持独立的实体遮挡顺序。侧视和极近距离可以看见分层边缘。

观舞段原画标尺下，抬槌圆头中心约在 (550.6, 110.9)，虚拟肘支点选 (531.5, 146)，取鼓沿附近的 (565, 167) 作接触位置。落槌绕此支点旋转约 93°，计算的槌头中心为 (565.4, 167.1)。鼓与座椅的景深和全高经过调整，落槌时两层的对应点在虚拟空间相距约 1 厘米。拍时对应模型姿态，听觉感受还受扬声器、系统缓冲和显示刷新影响。

## 修改与重建

`scripts/art/movement.py` 保存手工轮廓、支点和旋转角度。执行原画重建命令时，它从仓库内母版生成四张局部透明 WebP 和四张已处理的静态底图，并把关联写回 `art.json`。网页与离线 HTML 都装入这些素材。运行 `npm test` 可检查四个透明动件、支点、落槌与鼓沿距离，以及休止拍抬槌。图像依赖安装和完整母版重建步骤见[原画素材与许可](./原画素材与许可.md)。

```sh
PYTHONDONTWRITEBYTECODE=1 python scripts/art/build.py
npm test
```
