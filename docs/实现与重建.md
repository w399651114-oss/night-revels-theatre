# 从卷面到可回听的折屏

## 位置与时间

以卷首为零点，观者的卷轴进度从 0 到 27 米，世界坐标 X 随进度减小。五次停驻分别在 1.5、6.9、12.3、17.7、25.4 米。四道屏界位于 4.2、9.6、15.0、20.4 米。20.95 至 23.55 米保留可步行的空段。这些尺寸属于研究推定。[动线与边界](../src/route.js)

屏风由有厚度的箱体、两面画芯、漆木框、铜色收边和底足组成。相邻屏扇有小角度折转。路线接近屏端时向外侧偏移，再回到正常观距。近看与平移共用按实体屏端计算的安全距离。回退原路绕屏，快速定位也会经过中间路径。拖动可转身，滚轮改变视场角，右键横移结合纵向抬落，触屏支持双指捏合与平移。纵向行走由路线约束。[舞台](../src/scene.js) · [木构与展项](../src/details.js)

## 美术与几何重建

1. 先放置伏案、漆木屏、烛台与地面，验证五段能否连贯行走。在最终场景里，床榻和原画中交叠的人物使用保留原笔线的成组画片。
2. 将公版卷面裁成五张证据图。从可见笔线勾出人物、家具和乐器，局部使用色差优化边缘。难以分开的手、器物、坐榻可保留为同一组。三处使用邻近笔纹补全遮挡，在相应词条及图层清单中标识。[原画素材与可复现脚本](原画素材与许可.md)
3. 将裁片底边贴近绢地，分配到相对舞台中心的五个深度带，位置为 −0.72、−0.34、0、0.36、0.77 米。同带以毫米级微差维持遮挡先后。移动观察点便能比较前后层的相对位移。平面人物双面可见，背侧沿用原始纹理。
4. 使用同种材质合批绘制框条、腿足、榻前几案和器皿。花瓶以剖面旋转生成，屏上山水、木纹、丝线和烛晕由固定种子绘制。不同质量档改变像素比，节能档关闭动态阴影贴图。烛焰及近处点光随时间微动，屏端产生真实深度遮挡。舞者和弹奏者以幅度很小的转动提示动作拍点。[程序纹理](../src/textures.js)
5. 模型的完整输入为源码、轮廓与运行画片，构建时无需 Blender、glTF、Draco 或 KTX2。纹理采用浏览器原生 WebP，字体采用 WOFF2。构建会同时生成网站与离线 HTML。

## 音乐如何重建

首次开启声音时，应用以 24 kHz 生成 12 秒循环的三条单声道缓冲。弹拨声用基波、二三次谐波及指数衰减，鼓声用短促的降频振荡，管声用带缓慢颤动的持续音。音高与节拍见源码，音符序列由本项目设定。乐声不依赖采样包、商业录音或外部模型。[音色与增益函数](../src/audio.js)

三条缓冲共享起始时刻，各自经过增益节点及世界坐标中的 PannerNode，进入立体声主总线。距离采用反比衰减，参考距离 2 米，滚降系数 0.82。镜头朝向驱动听者左右声像。声源使用等功率声像，木屏不做频率相关的声学仿真。切换增益有 12 毫秒时间常数以抑制爆音。

| 对照项 | 固定起止与速度 | 甲 | 乙 |
| --- | --- | --- | --- |
| 听乐到观舞 | 2.25 → 6.15 米，0.66 米/秒 | 1.8 米起允许听见屏后鼓声 | 4.2 米屏线开启同一鼓声 |
| 清吹到散宴 | 18.60 → 24.75 米，0.66 米/秒 | 20.95 米后，管声基准增益在 4.5 米内递减为零 | 在 20.95 米入口收至静默，回到入口前重新开放 |

**重复实验。** 进入“声场实验”，选切片与版本，点“从同一起点试听”。两版复用标准镜头、音轨、时间零点、路线和速度，行走以音频时钟计时。也可以驻足后连续切甲乙，保留当前相位与位置。每次试听后可在视图面板下载参数 JSON。试验没有自动推断感受或记录参与者身份的功能。文学出处与历史解释见[考据与推定](考据与推定.md)。

## 字体重建

仓库随附两个可变字体的页面用字子集以及 OFL 文本。网页运行所需汉字已随包提供，系统中文字体作后备。修改大量界面文字后，可用以下步骤重取上游字体并更新子集。上游主分支会变化，逐字节重建当前界面可使用已提交的 WOFF2 文件。

```sh
mkdir -p /tmp/revels-fonts
curl -fL 'https://raw.githubusercontent.com/google/fonts/main/ofl/notoserifsc/NotoSerifSC%5Bwght%5D.ttf' -o /tmp/revels-fonts/serif.ttf
curl -fL 'https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf' -o /tmp/revels-fonts/sans.ttf
python3 -m venv .venv
. .venv/bin/activate
python -m pip install fonttools brotli
python scripts/fonts.py /tmp/revels-fonts
npm run build
```

## 已知观察限制

图中卷面能提供相对视线、姿态和遮挡线索，无法单独确定南唐宅第的尺寸、家具背面、音乐旋律或持续时长。侧视画片会变窄，重叠部分有残留边缘，绕屏动线对站位有约束。烛光和雾只参与画面表现。研究比较应记录所用设备、视口、画质、位置和两版次序。
