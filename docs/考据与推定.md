# 从画中可见到实验可听

北京故宫博物院将《韩熙载夜宴图》卷著录为五代顾闳中作、宋摹本，馆藏编号新00147326，绢本设色，纵28.7厘米、横335.5厘米。本幅无款。项目所称“原画局部”指这件传世画卷的数字图像裁片。网页将画中人物放入有纵深的场景，虚拟尺度、物件背面、烛光强弱、声音与行走速度均由实验者设定。[故宫藏品著录](https://www.dpm.org.cn/collection/paint/228200.html)

## 五段怎样辨认

| 展卷次序 | 可以在画中寻找的线索 | 原型提出的问题 |
| --- | --- | --- |
| 听乐 | 榻、红衣听者、琵琶和弹奏者 | 人还看着听乐时，下一段能否先进入耳朵？ |
| 观舞 | 舞者、执槌的主人和鼓 | 当鼓声已经出现，绕屏动作还会怎样改变对舞者的注意？ |
| 暂歇 | 净手的主人、侍女和榻 | 停留从走近榻边开始，观者也可以选择提早离开。 |
| 清吹 | 并坐的五位奏管者、敞衣的主人 | 离开乐队后，听见持续音会不会延长对这段的感知？ |
| 散宴 | 持鼓槌的主人、分组交谈的宾客与女伎 | 同一段留白，回头进入时会感到过了多久？ |

五段名称与人物、乐器的辨认采用故宫著录。界面的先后次序沿卷从右向左；历史上这些动作分别持续多久，画上没有计时标记。学者丁羲元曾从韩熙载更衣和宾客变化提出按“一、五、二、四、三”重读的解释。原型让观者按画面次序行走，同时保留回退与跳段，以便比较不同读法。[故宫藏品著录](https://www.dpm.org.cn/collection/paint/228200.html) · [丁羲元论音乐与空间构局](https://www.thepaper.cn/newsDetail_forward_24620712)

## 两个切片的名字怎样来

“别殿遥闻”节取李煜《浣溪沙》的“别殿遥闻箫鼓奏”。词里写远处的乐声，实验据此把鼓声进入的时间设在绕屏之前或绕过屏端之后。“过屏方启”是为后一条件拟的实验名称。[戴景素辑注《李后主词》，商务印书馆1930年版，第一期作品《浣溪沙》](https://upload.wikimedia.org/wikipedia/commons/a/a8/NLC511-023031404030157-37521_%E6%9D%8E%E5%BE%8C%E4%B8%BB%E8%A9%9E.pdf)

“凤箫吹断”节取同一版本李煜《玉楼春》。把“断”设成进入虚拟留白后停止管声，是项目对声音作的处理。“余音越界”和“留白静默”都是条件名称。这两首词描绘宫廷，作为文学参照单独展出。实际韩宅的声源方位、乐谱、曲终时刻并无据可从这两首词确定。[戴景素辑注《李后主词》，第一期作品《玉楼春》](https://upload.wikimedia.org/wikipedia/commons/a/a8/NLC511-023031404030157-37521_%E6%9D%8E%E5%BE%8C%E4%B8%BB%E8%A9%9E.pdf)

## 卷上实物文字

引首程南云篆书“夜宴图”。卷前隔水的南宋题语已经残缺。拖尾还保存无名氏撰写的韩熙载小传，交代部分人物关系与乐舞活动。这些文字分布在画心的前后，读者可据其位置核对文字与画面之间的关系。[故宫所刊题跋、书迹及释文，第58页](https://www.dpm.org.cn/Uploads/pdf/5069/T00058_00.pdf)

元代班惟志的卷后题诗署泰定三年（1326）。观舞段选“胡琴娇小六么舞”，散宴段选“与论庄王绝缨事”。前者连写乐舞，后者用典评人，末句针对全卷。把它们随段落并排展出，是为了说明后代观者如何读画；它们在实物上均位于画卷拖尾。[故宫所刊班惟志题诗释文，第59页](https://www.dpm.org.cn/Uploads/pdf/5069/T00059_00.pdf)

## 声画之间如何对照

一个可重复的比较是在同一点驻足，保持耳机、系统音量、相机朝向和位置一致，只切换一个切片的甲乙条件。再从相反方向走过同一段，观察听见声源和看见人物分别发生在哪里。来回阅读会带来熟悉效应；若进行正式被试研究，应记录条件顺序与方向，例如让另一组按乙、甲顺序体验。网页提供可比较的刺激，研究结论仍需实际观察和听辨数据。
