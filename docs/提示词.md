# GPT-6 Astra 实际使用体验测试 · 任务提示词

以下保留需求正文，统一了换行和编号格式。可用同一提示词在空白工作区重复实验。发布时使用执行者自己的 GitHub 账户。

> 请用 Three.js（最新稳定版）+ Vite 独立创建可在浏览器直接打开的《韩熙载夜宴图》立体折屏画卷交互网页，作为“中国叙事手卷的事件进程与虚拟空间设计”研究的前端实验原型。本版本完全独立，不依赖任何 Blender 资产导出。

## 核心设计立场

不要做成写实仿古建筑漫游或静态 3D 厅堂。把画卷本身转化为一条可驻足、可回退、可换位重听的立体折屏剧场。空间秩序随声音时序与人物行动而流转。所有推定必须在界面中明确标注，绝不宣称“完美还原”或“考古级复原”。

## 空间与视觉硬性要求

1. 整体为自右向左延展的线型素绢长廊（约 25–30 米虚拟长度），地面绢帛肌理，环境消融于温润素绢底色与摇曳烛光雾气，不建虚假屋顶与封闭墙体。
2. 人物、床榻、几案、乐器按原画笔墨设色做 4–5 层景深分层，产生真实运动视差。
3. 分割五段的折屏与座屏建为可真实遮挡视线的实体隔断；观者必须侧身绕过才能看到下一段。
4. “清吹”与“散宴”之间的素绢留白转化为可步行的“时间间隙廊道”。
5. 低饱和、暖烛光夜宴氛围，近景可见木构、织物、器物细节。

## 必须实现的核心交互与实验功能

1. 自由环视、缩放、平移 + 键盘/触控沿画卷动线平滑行进、驻足、回退。
2. 五个段落快速定位按钮，镜头平滑切换。
3. 两个受控对比实验切片（可一键切换甲/乙版本）。切片一（听乐→观舞）为方案甲“别殿遥闻”与方案乙“过屏方启”；切片二（清吹→散宴）为方案甲“余音越界”与方案乙“凤箫吹断/留白静默”。
4. 主要人物与器物的空间标签；点击打开简介，支持“走近看看”。
5. “三层证据并置溯源界面”：一键展开/收拢，下层 L1 原画局部与器物，中层 L2 对应诗词题跋与空间时间图解，上层 L3 当前声画版本参数说明。
6. 自动巡游、隐藏界面、全屏、画质切换、标签/线框开关。
7. 真实加载进度与错误提示。中文界面。

## 技术与性能

优先程序化 + 轻量几何实现折屏、床榻、人物，保证在 Apple M4 16GB 设备上流畅运行。静态几何合批/实例化，提供可切换画质。声音用 Web Audio 实现基本空间衰减与版本切换。页面、代码注释、README 全部使用简体中文。先做出完整可运行的最小场景，再逐步增加细节。
