# 部署、离线交付与 4K 剪辑

## 从空目录复现

```sh
git clone https://github.com/w399651114-oss/night-revels-theatre.git
cd night-revels-theatre
npm ci
npm test
npm run build
```

使用 Node.js 24。运行依赖固定在 package-lock.json。初次安装需要访问 npm，完成构建后可以断网。直接双击 dist/离线画卷.html，或双击同目录的 index.html，它会自动打开离线版。在线运行使用 npm run dev；交付静态构建使用 npm run preview。两个预览命令都默认监听本机回环地址。

网站入口把脚本、CSS、字体、画片清单路径相对当前文档解析；Vite 配置使用相对 base。网站文件发布到域名根目录或 /night-revels-theatre/ 均可。单文件离线版含同一脚本、样式、许可和经 Base64 编码的运行资产。[构建脚本](../scripts/standalone.mjs)

## GitHub Pages

1. 将源码推送到公开仓库的 main 分支。在 Settings → Pages → Build and deployment 中选择 GitHub Actions。
2. 推送触发“校验与部署折屏剧场”。构建作业在 Ubuntu 上执行 npm ci、边界及资产测试、Vite 构建，再用 Chromium 在仓库子路径与本地文件入口执行浏览器测试。
3. 仅 main 的构建产物进入部署作业。拉取请求只验证，不部署。Pages 用短期 OIDC 身份接收 dist 目录。工作流只给部署作业 Pages 写权限。
4. 打开工作流返回的 Pages URL。首页画片、字体与 WebGL 程序从本站相对路径加载。证据区的外链由观者主动打开。

可在本机复核已部署站点。测试通过浏览器执行真实导航、声音切换及下载，在临时浏览器上下文内保存文件。

```sh
npx playwright install chromium
npm run test:browser
CHECK_URL=https://w399651114-oss.github.io/night-revels-theatre/ npm run test:browser
```

系统已安装 Chrome 时可设置 BROWSER_CHANNEL=chrome。额外传入 --screens 可从当前构建重拍 README 截图，--media 会实际录制并解析数秒 4K 文件，检查画幅和音轨能量。

```sh
BROWSER_CHANNEL=chrome npm run test:browser -- --screens --media
```

## 导出与剪辑

1. 在桌面浏览器打开剧场，选择切片与版本，预走一次，确认声场和镜头。录制前选好构图。视图工具中的“下载 4K 画面”导出 3840 × 2160 的 PNG。
2. 点“录制 4K 声画”。画布以固定 3840 × 2160、16:9 渲染，音频来自剧场的 Web Audio 总线。导出包含 Three.js 场景；标题、证据面板与操作提示属于网页界面，如需录入这些元素请使用系统录屏。
3. 启动自动巡游或按住行进键。需要一组对照镜头时分别选甲、乙并从同一起点试听。暂停视点时录制继续；顶栏“结束录制”会生成浏览器下载。页面关闭前先结束录制。
4. 浏览器优先尝试 VP9 + Opus，其次尝试 VP8 + Opus、MP4 与浏览器可用的 WebM。目标 30 fps、视频约 20 Mbps。实际码率、帧数和音频格式由设备与系统编码器决定。长片可分段录制，减轻浏览器暂存压力。下载均通过 Blob 和 download 属性完成。
5. 将各段导入 Final Cut Pro、剪映或同类软件，建立 3840 × 2160 时间线，按章节切点裁切。甲乙片段保留同一走速与起始音，不要用不同变速或增益处理两版。需要解释时，在静止镜头叠加“研究推定”、版本名、对应文献和米数。以 H.264/H.265 和 AAC 导出。可用本机 FFmpeg 把下载的 WebM 转为剪辑软件常用的 MP4。

```sh
ffmpeg -i "夜宴折屏-4K.webm" -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart "夜宴折屏-剪辑用.mp4"
```

## 发布边界

仓库包含全部前端源码、场景参数、轮廓、配准母版、运行贴图、字形、第三方声明与现场截图。Pages 只发布 dist。开发依赖、原始高分 TIFF、工具缓存、软件安装包和影片均不入库。测试录像位于测试浏览器临时空间，自动校验后清理。观者主动下载的文件由浏览器保存在设备上。站点没有服务端处理器、上传路径、本地写文件接口、用户追踪或密钥。
